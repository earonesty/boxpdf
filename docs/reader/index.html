Open-source PDF extraction for JavaScript runtimes

Parse PDFs a page at a time.
Use the result as JavaScript data or HTML.

@boxpdf/reader reads PDFs from HTTP ranges, Blob objects, memory, or custom random-access sources. It extracts positioned text, fonts, paths, and images in Node, edge functions, and the browser. Cache limits are configurable.

import { httpSource, openPdf } from "@boxpdf/reader";
import { pageToHtml } from "@boxpdf/html-writer";

const pdf = await openPdf(httpSource(url), {
  maxBytes: 2 * 1024 * 1024,
  maxObjectCacheBytes: 2 * 1024 * 1024
});

const page = await pdf.getPage(0);
viewer.innerHTML = await pageToHtml(page, { profile: "visual" });

Reader features

Page extraction with explicit cache limits.

The reader exposes page dimensions, positioned text, fonts, vectors, images, and paint order as a JavaScript model. The HTML writer converts that model to positioned or reflowable HTML.

Bounded caches

Set limits for source bytes, decoded objects, individual objects, and cross-reference data. The reader reports peak cache use.

Portable sources

Use random-access HTTP, Blob, memory, or a custom size + read(offset, length) source. The parser is pure JavaScript.

Random page access

The reader resolves the page tree and requests the byte ranges for the selected page. It can seek directly to page one or page 10,000.

Visual HTML

The visual profile writes page coordinates, embedded fonts, images, SVG paths, opacity, rotation, clipping, and paint order to HTML.

Structured page data

Process extracted spans, paths, and images directly, or pass them to the HTML writer. Text spans retain page geometry and source references.

Two HTML output profiles

visual

Positioned HTML

Absolute positioning, page geometry, SVG vectors, embedded font programs, and paint order. Use it for viewers, previews, and PDF-to-HTML conversion.

semantic

Reflowable HTML

Infer reading order, sections, lists, cards, addresses, summaries, and tables across a bounded page window. See the semantic profile →

Install the reader and HTML writer

npm install @boxpdf/reader @boxpdf/html-writer

Random-access sources

openPdf(httpSource(url))
openPdf(blobSource(file))
openPdf(memorySource(bytes))

HTTP range requests, browser files, in-memory bytes, or your own size + read(offset, length) source.

Stream HTML pages

for (let i = 0; i < await pdf.getPageCount(); i++) {
  await write(pageToHtml(await pdf.getPage(i), {
    profile: "visual"
  }));
}

Process each page as it is extracted and write each HTML result to your output stream.
